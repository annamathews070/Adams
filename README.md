# Adams Property Solutions landing page

A responsive multi-page site served by NestJS, with shared HTML, CSS and JavaScript in `public/`.

## Requirements

- Node.js 20 or newer
- npm

## Run locally

1. Install dependencies with `npm install`.
2. Start development mode with `npm run dev` (or `npm run start:dev`). It chooses the first available port starting at 3000 and prints the URL.
3. Open the URL printed in the terminal.

Production build and start: `npm run build`, then `npm run start:prod`.

## Site features

- Responsive navigation and WhatsApp contact links with contextual prefilled messages to +91 7594 880 033.
- Separate Home, About, Services, Project, Contact, Privacy and Terms routes.
- Scroll-led cinematic hero with a rotating image slideshow, animated crystal atmosphere, and a keyboard-accessible image slider.
- Responsive mobile navigation, scroll reveals, reduced-motion support, and prefilled WhatsApp enquiries for each service.
- Service overview and project opportunity summary based on information supplied by Adams.
- The Home hero uses the supplied crystal-landscape image; proposal figures and dates are labeled as Adams-provided and require current confirmation.
- The supplied Adam’s logo is cropped and transparent in `public/adams-logo-transparent.png`; external photography and Google Fonts require an internet connection.
